# M-Pesa QR Code Generator 

This project demonstrates how to generate an **M-Pesa QR code** using Safaricom's **MPESA Daraja API (Sandbox)** in Python. It obtains an access token, generates a QR code for a payment, and saves it as an image.

## Features

- Authenticate with Safaricom's sandbox API
- Generate M-Pesa QR codes for payments
- Save the QR code locally as a PNG image
- Works with Python 3.x
